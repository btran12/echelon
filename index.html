Replay an unlock key

Paste a full response frame captured from the official Echelon app's unlock handshake. It is written to the F2 characteristic whenever the bike sends an F0 E0 challenge.

Where to get one: sniff the app↔bike handshake with an nRF52 dongle / Wireshark, or run a qdomyos-zwift "Virtual Echelon" bridge and copy the frame it proxies. Keys are rolling and short-lived, so a captured frame is only useful for that session — clear it afterwards.

Post-July-2025 Echelon firmware gates BLE telemetry behind a challenge/response handshake. The bike sends an 8-byte F0 E0 challenge and expects a 128-bit rolling key derived from a master key held on Echelon's servers, so the answer cannot be computed in the browser. To ride with this page, either use a bike whose firmware predates the lockdown, or capture one key frame from the official app's handshake (BLE sniffer or a QZ "Virtual Echelon" bridge) and replay it here — keys are single-use and expire quickly.
